# Extra Sermons

A planned mod for **Graveyard Keeper** that lets you buy permission for one additional sermon through **Royal Services**.

Keep the regular weekly service and purchase an extra opportunity when you need it. The initial proposed fee is **one gold coin per permit**; balance remains provisional.

## Status

Concept and repository bootstrap only. There is no playable build or release yet.

The adopted product scope and unresolved mechanics are in [docs/DESIGN.md](docs/DESIGN.md).
